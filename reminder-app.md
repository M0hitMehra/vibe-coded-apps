# Reminder App

Link for git-hub repo : https://github.com/M0hitMehra/Reminder-app-vibe_coded

Link to download app: https://expo.dev/artifacts/eas/hRMYyUkAqz6RPqon42Dt95.apk

A robust, fully-featured Reminder application built with React Native and Expo. This app allows users to create reminders with recurring schedules, track their habits with analytics, and use a "Puzzle Mode" to enforce discipline.

## Features

- **Local Storage:** All reminders and logs are kept private on your device using Async Storage.
- **Recurring Reminders:** Support for Daily, Weekly, Monthly, and Yearly reminders.
- **Push Notifications:** Deep integration with `expo-notifications` for OS-level local scheduled notifications.
- **Puzzle Mode:** Prevent accidentally dismissing alarms by requiring the user to solve a matching puzzle.
- **Analytics & History:** Visual charts, activity streaks, and a detailed chronological log of all app events.
- **Theming:** Full Light/Dark mode support with customizable accent colors (Ocean, Teal, Coral, Violet).
