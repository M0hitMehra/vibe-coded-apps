# 🔁 Recursive Corruption

Link for git-hub repo : https://github.com/M0hitMehra/social-mutation-vibe_coded

**An experimental, real-time social simulation that visualizes how trust erodes, beliefs mutate, and false consensus emerges within a network of autonomous agents.**

---

## 📖 Overview

Recursive Corruption is a browser-based simulation that models a small society of **84 autonomous entities**, each with their own personality traits — trust bias, memory persistence, suggestibility, honesty, greed, and belief certainty. These entities are connected through a dynamic social graph where they continuously influence one another's beliefs, memories, and trust levels.

The core premise is simple but unsettling: **introduce one small disturbance — a lie, a misremembered event, a stolen resource, a seeded contradiction — and watch the entire social fabric slowly unravel.** The system doesn't crash; it *drifts*. Beliefs converge on falsehoods. Memories rewrite themselves. Trust collapses silently. The simulation preserves the *form* of a functioning society while losing any stable account of what actually happened.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| **Live Agent Network** | 84 entities with unique personality traits connected via a dynamic trust graph rendered on an HTML5 Canvas |
| **Disturbance Injection** | Four types of social glitches — *lies*, *altered memories*, *resource theft*, and *seeded contradictions* — each with adjustable intensity |
| **Emergent System States** | The network self-classifies into conditions: *Stable*, *Unstable*, *False consensus*, *Total distrust*, or *Recursive instability* |
| **Entity Inspection** | Click any entity or use observation tools to inspect its internal reasoning, trust bias, memory persistence, belief certainty, and thought stream |
| **Ambient Feedback** | Real-time narrative readouts, system drift metrics, and dynamic color shifts that visually convey network entropy |
| **Responsive Design** | Fully responsive layout with graceful degradation across desktop, tablet, and mobile screens |
